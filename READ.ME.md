# Student Face Recognition Attendance System

## 1. Project Introduction
The Student Face Recognition Attendance System is an Artificial Intelligence and Machine Learning project developed using Python and OpenCV.

This project uses face recognition technology to identify students through a webcam and record their attendance automatically.

The system helps reduce manual attendance work and makes attendance management easier.

## 2. Objectives
- To develop an automated student attendance system.
- To identify students using facial recognition.
- To reduce manual attendance recording.
- To record student entry and exit times.
- To maintain attendance records in CSV format.

## 3. Technologies Used
- Python
- Artificial Intelligence (AI)
- Machine Learning (ML)
- OpenCV
- NumPy
- CSV
- JSON

## 4. Project Features
- Student registration using name and register number.
- Face image capture using webcam.
- Face recognition using a trained model.
- Student identification.
- Attendance recording.
- Entry and exit time management.
- Attendance storage in CSV format.

## 5. Project Files

| File | Description |
|---|---|
| register_student.py | Registers students and captures face images. |
| train_model.py | Trains the face recognition model. |
| face_engine.py | Contains face detection and recognition logic. |
| predict.py | Identifies students using the webcam. |
| attendance.py | Records student attendance. |
| requirements.txt | Contains required Python libraries. |

## 6. Installation

1. Install Python 3.11.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Install the required libraries.

```bash
pip install -r requirements.txt
```

## 7. How to Run the Project

### Step 1: Register Students

```bash
python register_student.py
```

### Step 2: Train the Model

```bash
python train_model.py
```

### Step 3: Test Face Recognition

```bash
python predict.py
```

### Step 4: Run Attendance

```bash
python attendance.py
```

## 8. Output
The system recognizes registered students using facial recognition and records attendance information.

Attendance details include:
- Student name
- Register number
- Date
- Entry time
- Exit time
